# 实施与验收计划

版本：2026-09-08。全部阶段除 P0 文档工作外均未开始。此计划属于长期项目设计，纳入版本控制；阶段完成必须附证据，不以文字状态替代测试结果。

## 1. 开发原则

先验证物理语义和可听辨性，再扩大后端覆盖。首次可用范围是 Windows + 手动关注 + 合成/回放 + 四个核心模式的最小配方。MuMax3/MuMax+ 实时适配随后接入；头部追踪在手动交互验证后实现。

拓扑模式与连续取向属于核心范围，不能以“后续增强”无限延后。通用性测试至少包括面内/面外方向、无壁体系和正负拓扑抵消；CDW 只作可选外部验收案例。

## 2. 阶段与完成条件

| 阶段 | 交付物 | 完成条件 |
| --- | --- | --- |
| P0：调研与定义 | README、概念、观测规范、能力调研、计划 | 公式/符号/版本边界明确，文档互链通过，Git 首个提交可复核 |
| P1：声音与输入小样 | 合成场源、规范 Sample、Windows 音频、ROI、小图与图例 | 连续播放、方位校准、正负音色与静态探听可用；不要求 GPU |
| P2：核心观察器与回放 | Activity、壁/连续取向、Band、Topology 最小实现 | 下面的物理测试与回放一致性通过；拓扑净零结构可听 |
| P3：后端与实时 | MuMax3 完整输出跟随、MuMax+ 采样适配、能力检测与限载 | 时间/缺口/预热正确，测量开销与数据覆盖；不改物理协议 |
| P4：泛化验证 | 双子晶格、独立公共案例、选定探针/耦合配方 | FM 与 AFM 数据语义正确；不依赖私人目录和参数 |
| P5：头部关注 | 姿态模拟器、一个经过验证的真实姿态源 | 回中/锁定/掉线可用，关注与声场姿态独立；完成延迟测量 |

P1 先用鼠标验证头控偏移逻辑；P2 先用 CPU 合成场与小型回放，不跑大参数扫描。P4 扩展到 NcAfm、Altermagnet、磁弹耦合中的哪些配方，依据 P3 实际版本能力和测试成本选择，未验证的配方显示 unsupported。

## 3. 首个实现布局建议

以下目录是建议，不在 P0 创建空实现：

~~~text
src/mumax_sonic/
  model.py             # 样本、实体、质量、观察与场景
  sources/             # synthetic、replay、mumax3、mumaxplus
  observers/           # activity、texture、band、topology
  attention.py         # 手动 ROI、后续姿态偏移
  mapping.py           # 量/符号/周期方向到声音参数
  audio/               # OpenAL Soft 适配与诊断
  ui/                  # 画面、播放、ROI、图例
examples/              # 可再生成的小案例及元数据
profiles/              # 明确物理适用条件和声音标定
tests/                 # 数值、数据流和映射验证
~~~

保持一个 Python 项目。先比较现成绑定与 ctypes 的最小表面积；音频由原生库执行。只有基准显示必要才加入进程隔离或新语言。案例生成脚本和小型元数据纳入 Git，大型数组通过可重现生成或外部 manifest 管理。

## 4. 物理与软件验证矩阵

| 验证场景 | 主要检查 | 阶段 |
| --- | --- | --- |
| 单一旋转方向、均匀磁化反转 | 活动量、真实时间、连续方向，无假拓扑 | P1–P2 |
| 面内与面外 180° 壁，扫描内角 | 壁运动和内角分开；角跨界无跳变 | P2 |
| 弯曲壁、多个交叉/分叉 | 不把匹配失败当高速运动；质量可见 | P2 |
| 正负拓扑纹理、净零双瓣、不同 helicity | Q+/Q−/Qabs/Qnet 语义和符号正确 | P2 |
| 涡旋与反涡旋、核心极性变化 | 绕数/极性/Q 不混淆 | P2 |
| 整体自旋旋转、物理轴变换、分层 | 拓扑与坐标约定、二维范围声明 | P2 |
| 带内/带外双频、空间反相、移动背景 | 抑制、相位抵消、背景泄漏与窗延迟 | P2 |
| 缺帧、乱序、阶段重置、跳转、半写文件 | invalid/stale/warming_up，不卡音频 | P2–P3 |
| 标准问题 4 公共案例 | 脱离 CDW 的反转回放/实时行为 | P3–P4 |
| AFM 两子晶格相反、序参量变化 | 净零仍有活动/纹理；标签定义持久化 | P4 |
| 官方磁弹/SAW 案例或其小型复现 | 量与单位、两个场的时间同步 | P4 候选 |
| 手动/模拟/真实姿态、突然掉线 | ROI 限幅、回中、稳定性和延迟 | P5 |

数值误差容差按离散法、网格与浮点精度制定，不预先承诺所有纹理 Q 严格为整数。解析场测试之外，对已知动力学案例检查量与原始画面。通过一个合成纹理不代表普适识别或稳定性证明。

## 5. 听觉实验

先做个人小样，不宣称一般人群结论。保存耳机、音量、HRTF、映射、随机顺序和试次记录：

1. 位置：单源左右/上中下与多源定位；对比普通声像与 HRTF。
2. 符号：同位置等响正负音色盲辨，再比较两符号相邻/重叠；必要时用交替探听。
3. 连续取向：缓慢扫角、跨 ±π 和已知旋转方向；测试映射是否有听觉混淆。
4. 强度：比较固定标定下的衰减和正负不平衡，检查压缩是否保留顺序。
5. 任务：后台发现变化、定位事件、主动找到静态纹理；记录漏报、误报、反应时间和主观疲劳。

初始工程目标：二选一符号盲辨不少于 20 个随机试次、正确率至少 90%；粗左右定位不少于 20 个试次、至少 90%。这是可调整的验收起点，不是统计显著性或可推广性结论。上下、多源和连续角先报告混淆矩阵，不为“通过”而悄悄修改分类。若失败，应修改声音映射/声源预算并记录前后结果。

## 6. 性能与时序验收

所有数值为待测目标：

- P1 预生成输入持续播放 30 分钟，记录 underrun/设备重连；目标无可检测断续。
- 数据就绪到声音控制生效的应用端 p95 延迟以 100 ms 为首个预算，另报驱动/耳机端到端延迟；不把物理滤波窗算成零等待。
- P3 同一小型仿真做关闭/开启监测的成对基准，报告 GPU、版本、网格、实体/分量、采样、现实帧率、墙钟耗时、CPU/内存与磁盘量。
- 可复用现有输出的低频纹理监测，先以额外耗时不超过 5% 为目标；高频全场模式单列预算，不承诺相同开销。
- 超预算先降低声源/画面成本或在物理要求允许时减采样。拓扑空间分辨率和频带时间采样不能随意牺牲；否则退出实时追赶、标记失效或转回放。
- 固定回放时间缩放时，改变读取速度不改变物理频率、速度、Q 和相对强度；允许音频块边界造成小的展示时序差异。

## 7. 待实验决定

- 连续取向的音色映射是否可学习，是否需要局部角+参考提示。
- 拓扑正负双音色、交替方式和正负对象预算；Qabs 噪声显示方式。
- 首版 3–4 声源是否足够；上下维度是否需要替代编码。
- 固定标定与可选慢增益控制的界限。
- Python 音频绑定与桌面 UI 选型；MuMax+ 实际采样接口开销。
- 真实头部追踪源；Windows AirPods 姿态不作为已解决依赖。
- 三维纹理和非共线磁序的后续不变量，需另写物理定义与测试。
