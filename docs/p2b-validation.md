# P2b：活动观察与时间契约

日期：2026-09-09。活动观察器、回放原始序号、时间导航和声音映射已接通，通过解析场与实际设备短测。完整 P2 尚需频带、OVF 回放及壁配方扩展。

## 物理定义

对同一体元的两帧完整 XYZ 向量，分别归一化为 u0、u1，计算：

    angular_activity = atan2(|u0 × u1|, clip(u0 · u1, −1, 1)) / (t1 − t0)

这与最短夹角的 acos 定义等价，atan2 可保留小角变化。单位 rad/s，时间是仿真秒；它是两次采样之间的最短角位移率，不是壁平移速度、LLG 力矩或区间内实际总转角。一次完整旋转仍可能与零转动混叠；大角步进警告不能排除所有混叠，真实采样间隔须根据研究对象验证。

有限非零向量经缩放后归一化，保留原始场模长。零模长、非有限分量和数值溢出的速率留为 NaN；材料 mask 不参与求方向。覆盖分母为当前材料体元数，固定真空孔洞不降低活动覆盖，材料边界改变则不跨边界变化计算。有效体元的均值和峰值可用于诊断；覆盖不足时整帧声音静音，不能将局部有效均值当完整域测量。

## 时间与质量状态

`angular_activity(previous, current, max_dt_s=None)` 是无状态的物理帧对计算，不读取墙钟时间。

| 输入情况 | 处理 |
| --- | --- |
| 第一帧无前一帧 | warming_up，无速率 |
| 连续动态帧、正时间差、实体/网格/材料不变 | 用实际 Δt 计算；允许非均匀正采样间隔 |
| 源序号前跳，或 Δt 超出显式上限 | warming_up，不跨缺口求差；后续完整相邻对可恢复 |
| 序号重复/回退，或时间不递增 | invalid |
| 阶段、实体、来源、网格或材料 mask 改变 | warming_up，不将变化边界当运动 |
| static 或 relaxation | unsupported，不赋予物理动态速率 |
| 部分材料向量无效或速率溢出 | 保留可计算体元，整帧 invalid 并静音 |
| 相邻帧方向不变 | valid、速率 0；与缺数据严格区分 |

`max_dt_s` 默认不设置，不从文件时间间隔猜测采样周期。阈值边缘仅允许 1e-9 相对浮点容差，防止时间相减误差导致等于上限的间隔被错判。没有原始帧号、又未声明间隔上限时，不能保证识别漏帧。

## 回放与交互

`FieldReplay.pair_at(t)` 返回记录中的当前帧及其源记录前驱，绝不用上一次屏幕显示帧作前驱。因此慢放、快放、重复显示、向前或向后跳转，只选择不同的预先定义物理帧对。若跳转目标有可靠相邻源帧，可直接重建局部活动；目标是首帧或紧跟缺口则保持未就绪。不会将跳转前后不相邻帧误算成运动。

暂停不推进物理时间；开启“暂停时探听静态”保留当前区间的测量值，关闭则只静音，不修改活动数值。末帧自动暂停。窗口新增 0.25/0.5/1/2/4 倍速、按 ns 跳转、上一帧/下一帧、回放拓扑/活动选择、最大活动间隔设置。合成动态场以固定 50 ps 物理间隔采样，不使用 UI 刷新间隔。

此前 `session.Timeline` 是 P1 的独立原型守卫，仍保留兼容；P2b 实际活动路径使用物理 `FieldFrame` 帧对及上述检查，不声称已实现实时输入的流状态机。单个回放文件仍固定阶段、实体和几何，跨阶段行为通过观察器帧对测试验证。

## NPZ v2 与兼容

在 P2a 的 vectors、mask、times_s、metadata 字段外，新增：

- `sequences`：长度 nt 的 int64 原始帧序号，严格递增但允许间断；不随显示、保存或加载重编号。
- `provenance`：长度 nt 的 Unicode 来源说明，保存后保留；加载时附加当前文件 SHA256 和原来源类型。
- `metadata.schema_version=2`。时间必须有限、非负、严格递增；网格、实体、阶段不变。

v1 仍可读，但其缺失的序号只能按记录顺序推断，显式标记 `sequence_inferred:v1` 并显示警告，不能用这些推断值证明无缺帧。v2 写入不覆盖文件，禁用 pickle 和 256 MiB 读取限制沿用 P2a。诊断 JSON 将不可用的数值输出为 null；内存中的 NaN 仍保留科学无效语义，不写成 0。

## 空间与声音映射

保持已计划的渐进聚合安排。本批仍用固定 4×4 空间块，在每个体元求活动后，以“块内速率之和 / 全材料体元数”形成非负贡献；覆盖完整时所有块相加等于全材料平均活动。位置为局部速率加权中心，原始均值与峰值在选源前计算，不随 ROI 或播放速度变化。

活动使用单一非负声部，GUI 停用正负 solo，避免之前的负通道选择掩盖活动。默认声音参考为 1e9 rad/s；`--activity-reference-rad-s` 可调，仅改变增益与圈大小，不改变原始物理量。平方根压缩、最多 4 路和圈外背景策略沿用现有原型。局域峰值仍显示，但它不保证一定被独立播放；自适应聚合和覆盖统计仍按整体计划推进。

## 可复现运行

```powershell
python launch.py --field-demo activity_localized
python scripts/make_field_demo.py local/activity-example.npz --scenario activity_rotation --frames 8 --drop-frame 3
python launch.py --replay local/activity-example.npz --recipe activity
python launch.py --inspect-field local/activity-example.npz --recipe activity --max-dt-ps 50 --report local/activity-report.json
python launch.py --audio-smoke 8 --field-demo activity_rotation --report local/activity-audio.json
python -m pytest -q -rs
```

生成器的 `--step-ps` 指定物理间隔，`--drop-frame` 删除源序号但保留缺口，`--time-kind` 可验证动态、静态和松弛状态。命令行最大间隔单位为 ps，窗口为 ns，标签明确；二者均转换为 SI 秒后计算。
