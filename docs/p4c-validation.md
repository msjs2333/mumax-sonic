# P4c：真实频带案例验证

2026-09-22。本批使用真实 MuMax3 无阻尼进动，对现有频带观察器进行带内、带外和反相验证。未更改生产观察器、读取方式或音频线程；P3e 仍待实际瓶颈触发。

## 复现与范围

[案例说明](../examples/frequency_band/README.md)列出物理参数和完整命令。[运行器](../scripts/run_band_case.py)生成三份明确的 `.mx3` 并执行真实求解；[验证器](../scripts/validate_band_case.py)只读已完成的清单，使用固定参数和验收容差。该测试不依赖 CDW。

最终数据位于 `local/p4c-band-20260922/`：三组各 320 帧，保留实际脚本、日志、运行命令、退出码、全部 OVF 和 `validation.json`。MuMax3 3.12 / CUDA 12.9，RTX 5060 Laptop GPU。各次求解退出码为 0；耗时约 13.75、3.39、3.39 秒，包含进程初始化和文件输出，不代表监测开销或实时音频延迟。

本例关闭交换和退磁，让所有体元独立进动，因此具有解析频率与幅值参考。它验证真实求解器输出的频带语义，不验证传播自旋波色散、空间耦合或某种材料模型。

## 物理窗口与验收

每个序列从 0 开始保存 320 帧，实际时间间隔约 5 ps、末帧 1.595 ns。分析窗口为 256 点周期 Hann，z 参考轴，8–12 GHz 频带，分辨率 0.78125 GHz，Nyquist 100 GHz。窗口的首末时间跨度为 1.275 ns，DFT 周期为 1.28 ns，二者分别记录。

每组前 255 帧预热，后 65 帧有完整有效窗口，不能把预热作为强度零。频率由完整 XYZ 中的横向相位拟合验证；幅值、带内功率与解析等锥角进动比较。容差预先冻结：载频相对误差 0.1%、横向幅值绝对偏差 10⁻⁴、带内功率相对误差 0.2%、带外均方功率小于 10⁻⁸（解析带内参考的 10⁻⁶）。

| 项目 | 本次实测 |
| --- | --- |
| 同相/反相带内平均功率 | 均约 0.0100000734，解析值 0.01 |
| 带内有效窗口功率范围 | 约 0.0100000639–0.0100000800 |
| 带外平均功率 | 约 2.525×10⁻¹⁷；不裁成零 |

| 窗口状态 | 每组 255 预热、65 有效，共 960 输入帧、195 有效窗口 |
| 声音参数 | 固定强度参考 0.01，自适应预算 8，保留原始强度贡献 |
| 模拟增量发布 | 反相组 320 帧与离线结果完全一致，无跳过解码，末尾保留两帧 |

反相组横向空间均值抵消，局域频带功率仍与同相组相等；这直接验证了先逐点频谱求强度再聚合的必要性。有限频带积分仍会有泄漏，本案例的两载频恰好处于整数 DFT 频点，不能将这里极低的带外残余推广到离栅频率、短窗或非平稳纹理。

反相组的增量检查模拟的是对存档逐帧发布，不是实时求解与播放并行。解码 320 帧，末尾两帧向量与掩膜共 1600 字节；不含进程、频谱历史或离线测试缓存。首次检查因系统临时目录权限失败，按权限流程重跑后通过，没有改变生产代码或目录 ACL。
