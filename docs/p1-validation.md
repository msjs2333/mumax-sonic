# P1 实现与验证记录

日期：2026-09-08。结论：合成声源原型可运行，自动检查和短时 Windows 设备检查通过；人工听觉、长时稳定性和真实物理验证未完成。

## 已实现

Python 标准库 Tk 窗口、ctypes OpenAL Soft 音频线程、确定性合成源、手动 ROI、双符号共享参考尺度、暂停与静态探听。默认窗口不发声，由用户开启试听。音频采用原生循环缓冲，控制线程仅消费最新场景；0.75 秒无更新会标记 stale 并停声，运行期音频错误转 error，可手动重连。

P1 最小契约为不可变 `Observation → Sample → SonicScene`：物理位置用米、时间用仿真秒、强度非负、符号独立，保留实体/量名/单位、版本和质量。声源通过稳定 ID 对应观察值。它不是完整场数据接口：规范轴元数据、完整观察引用、真实输入回放及时间线接入留到 P2。`Timeline` 目前是独立受测防护组件，GUI 使用本地合成源。

ROI 只影响选源与增益，不改变观察值。先预留内区弱源和正负通道，再裁到 4 个声音；视图仍显示所有输入。位置映射到前方 ±60° 方位、±30° 仰角和固定虚拟距离。增益共用固定参考并采用平方根压缩，正负 solo 不重新归一化；后端平滑增益和位置。

正负采用 220/330 Hz 加二次谐波的听觉标签，数字 RMS 约 0.25；不是物理自旋波频率，也未校准为感知等响。连续取向标签跨周期连续，但仅用于箭头/数值显示，未实现声音映射。所有场景均明确标为 synthetic，标签净值不是 Q，未计算 q/Q 或从畴壁提取方向。

## 已运行证据

环境：Windows、64 位 Python 3.13.12、Tk 8.6，OpenAL Soft 1.25.2 官方 Win64 DLL。依赖安装保留 COPYING 和来源清单在本地；仓库不包含 DLL。
