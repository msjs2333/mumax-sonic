# P3d：暂时完成与后续安排

2026-09-12。按用户要求，为当前链路的小幅性能优化设置停止边界：**P3d 暂时完成，保留可用实现与诊断基线；严格性能验收尚未全部通过。**

## 已交付与保留限制

已完成 MuMax3/MuMax+ 基础接入、增量读取、真实物理时间与失效状态处理、活动关注区优先计算、低频背景概览、声源预算与平滑，以及持续输入/分项成本工具。随后移除实时内容审计和不必要的巨大读取缓冲，复用 ROI 帧与分块结果，省去丢弃的贡献网格，采用有界活动核与控制周期补偿。

当前关注区是即时局部观察与较旧背景概览的组合，不是全场当前积分；体元计算保持完整 XYZ 与物理时间，注意 ROI 不重新定义拓扑积分域。真实案例支持当前尺寸与约定输入节奏下的可运行性，不构成任意输入速率的保证。

未通过或未完成：稳定的 100 ms 应用端 p95、间歇读取/控制长尾归因、每帧控制应用保证、30 分钟设备与声学延迟验收、严格 <5% 监测开销结论，以及真实频带局部缓冲的持续验证。已有短测无 stale 或零音频丢弃不能替代这些验收。

## 本轮有限对照

已完成 A1（计时关）→B（计时开）→A2（计时关），各 80 秒、四场景各 20 秒。同一原备份路径的真实 1500×500 存档场、约 1.426 秒/帧、目标预算 8、stale 2 秒。各轮使用新进程；不清空系统缓存，不启动 GPU 求解器。这是小样本观察对照，不是严格随机因果实验。

| 发布→控制 p95 | A1 关 | B 开 | A2 关 |
| --- | ---: | ---: | ---: |
| 小圈静止 | 135.3 ms | 113.5 ms | 96.1 ms |
| 大圈静止 | 136.3 ms | 124.2 ms | 133.0 ms |
| 小圈拖动 | 103.2 ms | 91.8 ms | 100.0 ms |
| 大圈拖动 | 131.7 ms | 147.3 ms | 140.8 ms |

三轮读取中位均约 23–25 ms；关闭计时也出现正常读取，未发现计时开启带来一致提速。各轮 57 帧全部观察到，56 帧记录到有效控制，仅首帧 0 预热；未抽样到 stale，发布/读取错误、音频异常停止和丢弃更新均为零。每个场景仅约 14 个发布帧，p95 受个别样本影响，不能用某格接近或小于 100 ms 宣称稳定通过。

此前的读取/控制长尾在本轮没有复现，原因仍未确认。当前没有发现可凭现有证据继续实施、并稳定达到全部目标的小改方案；按用户指定边界停止本阶段的迭代，将结构性方案留待 P3e。

本轮生产算法未改动，只修正持续测试脚本在拆分 `run` 后未传入参数解析器的问题，使无效时间清单正确报错而不是触发 NameError；新增三项命令行错误路径测试。相关诊断与计时测试 **6 passed**，脚本语法及补丁格式检查通过。上一批完整回归 **288 passed**；本轮未重跑完整套件。真实设备运行只验证归档场驱动 Tk/OpenAL 的控制链路，未做新的 GPU 仿真或人工试听。

## 后续分配
