# P3d：活动核的内存与计算优化

2026-09-10。本批优化大关注区的逐体元角活动计算，保留原始空间分辨率、相邻物理采样时间与完整 XYZ 方向。

## 方法与边界

旧核为两帧建立整场归一化向量，再通过布尔索引取出材料体元，构造叉积等临时数组。新核逐行处理，每个向量先除以自身最大绝对分量，再计算 `atan2(|a×b|, a·b) / dt`。两个向量的正尺度因子在 atan2 中抵消，无需进一步单位化；缩放后的乘积有界，仍支持极大及极小的有限非零向量。

只保留整场标量速率和有效性输出，向量临时量限制在一行内。未增加依赖、哈希或物理降采样。时间、序号、几何、材料掩膜、零向量、非有限值、速率溢出及接近 π 的采样混叠提示保持原契约。注意区前景与较旧后台概览的语义不变，仍不能解释为当前全场积分。

## 独立计算测量

同一份真实 CDW 两帧的 500×752 关注区，旧核从上一提交导出，同进程分别重复五次。两帧裁剪中位约 9 ms；旧核中位约 284 ms，其中单独测量的两帧归一化约 144 ms；新核约 72 ms。包含贡献网格和诊断构造的局部观察约从 316 ms 降到 126 ms。各阶段分别重复，不能相加为端到端分位数。

这是原始备份场的独立 CPU 测量，没有求解器、界面或音频负载。性能随机器、缓存和调度变化，持续链路结果另列。

最终再次运行，旧/新核中位为 306/123 ms，完整局部观察为 443/179 ms，说明单次微基准有明显波动；不能承诺固定 3.9 倍加速。真实场逐体元结果最大绝对差约 `2.52e-5 rad/s`，通过 `rtol=1e-9, atol=1e-3 rad/s` 的比较，有效体元、状态和警告一致。
