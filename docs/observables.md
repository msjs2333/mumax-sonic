# 物理观测、连续取向与拓扑符号

状态：2026-09-08 设计规范，公式为拟实现定义，尚未通过本仓库数值或听觉验证。适用条件是接口的一部分，不将配方外推成普适分类器。

## 1. 通用原则

把连续场、派生量和事件标签分开。选定观察对象可为单位磁化 m、某一子晶格 m_a、定义明确且非零的序参量方向 n，或有单位的标量/向量场。归一化之前保留原模长；无材料、零模长、缺数据和奇异点是无效状态，不是普通方向。

声音参数分工：位置表示物理位置，响度表示非负强度，连续音色/调制表示选定的连续取向，离散符号采用可辨识的独立声部。物理符号不能通过负音频振幅表达——反相不提供可靠的正负听觉编码。

## 2. 活动

对于归一化且同一坐标系中的方向 u：

    angular_activity = acos(clip(u(t) · u(t−Δt), −1, 1)) / Δt

该量仅是采样之间的平均角变化速率；不能恢复间隔内的完整旋转，超过采样分辨率会低估/混叠。其他量可使用带单位的差分、RMS 或后端力矩，必须命名其定义，不把 LLG 力矩、总导数和有限差分自动当作完全等价。

热噪声背景需要同温度、网格、采样条件下的基线。不能用逐帧分位数拉满所有背景。优化过程使用收敛配方，不计算物理速度/频谱。

## 3. 连续取向：默认不二分为正反

### 3.1 通用方向表达

底层保留完整三分量方向及选定基底。相对参考方向可用夹角 acos(u·u_ref)；它丢失旋转轴和旋转方向，只适合“偏离程度”。需要完整方向时保留局部三分量或球面坐标，角度的周期性与极点有效性必须显式处理。

面内壁的取向同样连续。只有在动力学被限制在少数稳定构型、并且用户选择相应模型时，才派生极性或翻转阈值；不把某个 m 分量变号当作通用异常。

### 3.2 畴壁的局部内角

对于存在可区分两侧磁畴的壁，首先定义有顺序的两侧域方向 u_A、u_B。近反平行情形可取：

    d = normalize(u_B − u_A)
    p = u_core − (u_core · d) d
    φ = atan2(p · e2, p · e1)

其中 (e1,e2,d) 是有明确取向的局部正交基底，e1、e2 张成垂直于 d 的平面。|p| 过小时 φ 无效。使用 (cosφ,sinφ) 做缓存、平滑和插值；不线性平均接近 −π 与 +π 的角度。

基底可由壁法向在 d 垂面上的投影构造；当投影退化时使用连续输运或声明的参考轴，必须记录选择。壁形变造成的基底转动与磁化自身转动分开保存，避免坐标变化听成壁芯转动。实验室方向与局部内角都应可查询。

在 PMA 薄膜且 d 沿膜法向的常见情形，局部内角可表达 Néel/Bloch 及中间态；在面内易轴体系中则围绕其实际域轴定义，不能沿用 PMA 的固定 m_z 符号。非反平行多域、交叉/分叉和三维壁面需独立几何配方；不得伪造单值内角。

### 3.3 壁位置、运动和形变

优先以 u·d 的过渡、几何连续性和域标签定位。单值 x(y) 只是一种简化，通用输出允许曲线/区域和多对象。时间关联需报告匹配可信度；多交叉或分裂时不强制继承单个 ID。

分开输出：法向位移/速度、宽度、曲率、内角 φ 与其变化。第一版只选运动和内角中的少数听觉维度。持续不动称 stationary；pinning/depinning 需要几何、驱动及持续时间等配方证据。

取向音色映射需周期连续，例如对 (cosφ,sinφ) 构造周期性的参数轨迹；不能在 ±π 处跳音，也不能仅用 cosφ 丢掉 φ 与 −φ 的区别。实际可辨识度通过盲听验证，失败时改用主动探听和数值图例。

## 4. 频带

对选定动态场 δu，经物理频带 B 的因果滤波后，定义：

    P_B(r,t) = window_mean(sum_c δu_B,c(r,t)^2)

若选择磁化横向振荡，c 对应相对明确参考方向的两个横向分量；固定近 ±y 背景中的 mx/mz 只是特例。对移动/旋转背景要区分慢纹理与快振荡；过快更新背景会滤掉目标低频模式。局部基底随时间转动也可能引入假相位，需要固定或连续输运并记录。

P_B 是对应物理量的均方强度：单位是输入单位的平方，不默认称瓦特、能流或 magnon 数。对已知载频可用复数解调加低通；一般频带可用带通/短时谱。先逐点滤波、平方再空间聚合，避免相位相反的波在平均场中抵消。

采样率要覆盖可能混叠的实际信号，不能仅看目标频带。严格低于 Nyquist 不保证滤波性能；验证过渡带、带外抑制、泄漏、预热和群延迟。非均匀输出必须用真实时间并经合适的重采样/估计，不能盲用普通 FFT。50 GHz/5 ps 可作采样充足性实验起点，不是适用所有高次谐波的默认配置。

频带越窄，建立可靠结果需要的时间尺度越长，通常与 1/带宽 同阶；显示物理窗宽和现实等待时间。单帧、缺帧、跨阶段时间重置及回放跳转都触发 invalid/warming_up。

可选保留复相位、互谱或方向相关分量，以后分析传播和耦合。仅有局域强度不能唯一判断传播方向，同频的壁模/局域进动也不会被频带选择自动排除。

## 5. 拓扑模式是核心模式

### 5.1 明确对象和有向积分面

第一版计算单位向量场 u 在有向二维截面上的 skyrmion 密度：

    q_xy = u · (∂x u × ∂y u) / (4π)
    Q = ∫ q_xy dx dy

默认物理 (x,y,z) 为右手系，积分面正法向为 +z。坐标用米时 q 的单位为 m⁻²，Q 无量纲。选择其他截面必须记录两个有序切向轴和法向。

交换 x/y 或反转有向积分面会改符号；屏幕显示时翻转 y 轴不能偷偷改物理 q。整体自旋的正旋转保持 Q，u→−u 会令 Q 反号。对多层输出 Q(z) 等切片量，不把层求和自动宣称为一个二维拓扑荷，也不把它当作 Hopf 指数。

纹理的同伦含义取决于序参量态空间和边界条件。光滑、固定背景的二维场可有整数 Q；有限 ROI、开放边界、截断结构和 meron 背景不要求整数。Q 不取整后再播放，不能只凭接近 ±1 给对象命名。

### 5.2 正负同时保留

约定负通道存储绝对量：

    q_pos = max(q, 0)
    q_neg = max(−q, 0)
    Q_pos = ∫ q_pos dA        (≥0)
    Q_neg = ∫ q_neg dA        (≥0)
    Q_net = Q_pos − Q_neg
    Q_abs = Q_pos + Q_neg

默认提供正负双声部：各自按空间贡献定位、按非负大小映射响度，并用不同但经过等响校准的音色区分。两种音色没有“好/坏”“稳定/不稳定”的含义。它们共享物理参考尺度，不能分别自动归一化后抹平不平衡。

用户可以选择 both、positive-only、negative-only、absolute、net-summary。筛选必须明确显示，原始正负量仍保留。absolute 丢失符号，只作定位；net-summary 丢失空间抵消信息，不作默认声场。

一个 Q_net≈0 而 Q_abs>0 的正负双瓣结构仍应有声音。空间正负斑块是贡献，不等于两颗独立拓扑粒子；对象配对与稳定性分类另行验证。也不预设所有 bimeron 或 meron 配对都是净零，必须由具体构型与约定计算。噪声也会产生 Q_abs，不能将其称为“拓扑对象数量”。

两声部空间靠近时可能互相掩蔽，提供 solo、短时交替探听和图例；不为了符号把所有正值放左、负值放右。固定拓扑态在状态探听时持续可听，在动态监听时也可有低音量定位层，变化提示独立。

### 5.3 不混淆四种信息

| 信息 | 表达的物理内容 | 声音设计约束 |
| --- | --- | --- |
| q / Q 符号 | 有向积分面上的映射贡献 | 正负独立，不能由 polarity 猜测 |
| 绕数 w | 指定闭合回路上的投影角绕转 | 回路方向、投影平面和非零投影条件明确 |
| 核心极性 p | 核心方向相对指定轴/背景 | 只在极性配方成立时使用 ± 标签 |
| helicity / 壁内角 | 连续旋转构型 | 保留周期性，不强行二分 |

投影绕数可按 w=(1/2π)∮d arg(u·e1+i u·e2) 定义；回路上投影为零则失效。涡旋的环流方向与这个绕数也不能简单混为一谈。Q 符号本身不充分区分 skyrmion/antiskyrmion；参考[反 skyrmion 理论](https://www.nature.com/articles/ncomms10542)。

### 5.4 子晶格与序参量

AFM 优先显式选择各子晶格 Q_a 或明确定义、有效归一化的 Néel 场 Q_n。对子晶格求和可能抵消，但纹理仍存在。交换子晶格标签会改变所定义 Néel 方向及其 Q 符号，所以标签约定必须持久化。

对于 NcAfm 等非共线磁序，支持各子晶格观测不等于解决整个磁序的拓扑分类。只有已确认态空间和不变量的配方才可输出相应“拓扑标签”；通用三分量输入不得自动获得 FM 拓扑解释。

### 5.5 数值方法和质量

先在原始足够分辨率的有效材料上计算，再做声音聚合。初步采用两种估计交叉验证：中心差分 q 用于直观密度图；有向三角形立体角法用于几何拓扑荷。参考[晶格拓扑荷方法](https://arxiv.org/abs/2006.13336)。

几何候选公式，对有序单位自旋 a,b,c：

    Ω = 2 atan2(a·(b×c), 1+a·b+b·c+c·a)
    Q_tri = Ω/(4π)

每格三角化、有向顶点顺序、周期跨界和贡献分配要固定并测试。Q_tri 是无量纲贡献，显示密度需除以明确面积；与差分密度的正负积分不保证逐点相同，不能混用方法比较 Q_abs。

mask 边缘不补零磁化来差分，不跨真空连接三角形；近反平行三角形、方向无定义、强梯度和欠分辨纹理给出质量标记。报告网格、方法、边界覆盖、Q 的估计差异，保留原始结果。若为听觉去噪，阈值只作用于播放层并显示，不悄悄修改科学积分。

### 5.6 事件只是观察到的变化

可以提示“正贡献增强”“负斑块进入 ROI”“局域 Q 变化”“对象追踪丢失”。Q 变化也可能来自边界流出、ROI 移动、欠采样或数值误差；不能自动等同于成核、湮灭或拓扑相变。注意 ROI 的移动不改变物理积分域；移动分析 ROI 则需要单独记录。

## 6. 必须通过的验证

- 方向任意旋转、跨 ±π、局部基底退化和可控 φ 扫描；同一物理构型换坐标表达时映射语义保持一致。
- 均匀场 q≈0；解析二维纹理网格收敛；u→−u 与有向面交换符号反转；整体自旋正旋转保持 Q。
- 正负对消结构 Q_net≈0、Q_abs>0；两声部均存在，solo 不改数值。
- 不同 helicity 但相同 Q 的构型不会被拓扑模式误报为不同 Q；绕数和极性另行核对。
- 有限边界、缺口、分层和周期边界；下采样不能悄悄消掉纹理。
- AFM 子晶格相反时不因净 M 或 Q 求和为零而消声；Néel 模长无效区被识别。
- 频带内/外双频、反相空间波、非均匀时间、缺帧和频带切换；通过可量化的滤波误差和预热检查。
- 听觉盲测比较正负音色识别、位置识别、近距离双符号掩蔽及幅值比例；不能仅凭“听起来有区别”宣称有效。
