# P3d：关注区局部观察的精简

2026-09-11。本批接续活动核优化，减少物理计算完成后的数据构造与重复统计。

## 实现

- `observe_field` 增加 `activity_contributions=True` 参数。关注区局部观察显式设为 False，省去逐体元坐标、正负贡献网格及其只读副本；保留分块摘要和完整诊断。合并后的关注区结果仍提供紧凑贡献网格，供现有自适应聚合使用。
- 普通全场观察及小网格回退保留完整贡献网格；其他观察配方不受该选项影响。
- 活动分块使用连续切片，分区保持原有 `array_split` 的大小和顺序。质心通过行列边际权重与一维物理坐标计算，减少高级索引复制与二维坐标乘积。
- 均值、峰值各取一次，复用于摘要、诊断及聚合统计。

逐体元角速率、采样时间、掩膜与有效性契约不变。前景强度仍按完整材料体元数归一化；背景保留较旧时间，不与前景重复计数，也不声称提供当前全场均值。未新增哈希、历史审计或重复输入验证。
