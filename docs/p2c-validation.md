# P2c：频带观察与验证

日期：2026-09-09。已实现 CPU 解析场、NPZ 回放和 Windows 窗口中的频带最小配方；不是实际 MuMax 自旋波验证。OVF 导入、移动背景分离、传播方向、频带相位和自适应聚合仍待实现。

## 使用

```powershell
python launch.py --field-demo band_mixed
python launch.py --field-demo band_opposite
python scripts/make_field_demo.py local/band.npz --scenario band_mixed --frames 320
python launch.py --replay local/band.npz --recipe band
python launch.py --inspect-field local/band.npz --recipe band --report local/band.json
```

合成场景有带内 10 GHz、带外 30 GHz、10 GHz 空间反相及 10/30 GHz 分区。默认采样 5 ps，17×17 网格，横向振幅 0.1，背景沿 +z，完整 XYZ 保持单位模；奇数网格分区为 8/17 和 9/17。它们是解析振荡，不宣称满足某个材料的 LLG 或波动方程。

点击播放收集历史；也可直接跳转至 1.5 ns，用已有解析历史重建窗口。默认 256 帧、8–12 GHz，完整历史跨度 1.275 ns。回放末尾保持最后测量值。改变倍速只改变浏览速度，不改变频谱。

窗口可设置频带上下限、窗口帧数及参考轴 XYZ；“应用频带”重算目标帧之前的历史。命令行对应 `--band-low-ghz`、`--band-high-ghz`、`--band-window`、`--band-axis X Y Z`。回放配方下拉框仅作用于 NPZ，解析场景的配方由场景决定。非法配置保留上次有效设置并显示错误。

声音使用固定均方参考 0.005（`--band-reference` 可调），正负 solo 停用。沿用原有合成音色，以强度调节声音，GHz 不是可听载频。物理强度先按 4×4 分块汇总，最多选择 4 路输出；全场结果不受 ROI 影响，未选入贡献尚未通过背景汇总保留。

## 数值定义

对每个材料体元，以完整三分量归一化方向 u 和固定单位参考轴 d 得到横向向量 `p = u − (u·d)d`。保留三个笛卡尔分量计算平方和，等价于两个正交横向分量。逐体元减去当前历史窗的时间均值，再乘周期 Hann 窗，进行单边实数 FFT。

长度 N、窗函数 w、频谱 F 的各频点功率为 `|F|² / (N Σw²)`，除 DC 和偶数 N 的 Nyquist 点外加倍。将中心频率落在闭区间 `[low, high]` 的频点功率、三个分量相加，最后才做空间聚合。此归一化对应窗加权均方值；对于稳定且频带充分覆盖的正弦，测得振幅平方的一半。参考 [NumPy FFT 定义](https://numpy.org/doc/stable/reference/routines.fft.html) 与 [SciPy periodogram 约定](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)，实现仅依赖 NumPy。

这是只使用过去记录的有限窗谱估计，不是理想砖墙滤波器。默认分辨率 `1/(N Δt) = 0.78125 GHz`，实际选入中心为 8.59375、9.375、10.15625、10.9375、11.71875 GHz；诊断完整记录这些中心。边界附近会泄漏，且窗越短分辨率越差，不保证任意带外信号都被消除。

均方强度无量纲，基于归一化方向，不是原磁化模长的平方、能量、瓦特或 magnon 数。固定背景下的横向选择不自动分离移动畴壁、背景进动或热噪声，也不识别传播方向。存在目标频带外、Nyquist 以上的真实运动时仍可能混叠，不能仅凭目标上限判断原始采样充分。

## 时间与有效性

- 只分析截至目标帧的最近 N 帧，无未来数据；短窗为 `warming_up`，不会补零制造低强度。
- 帧号缺口、实体/阶段/网格/材料掩膜变化后，从最新连续段重新累计 N 帧；乱序或重复时间/序号为 `invalid`。
- 当前实现拒绝非均匀采样；间隔比较采用相对容差 1e-6。静态和松弛记录为 `unsupported`。上限须严格低于 Nyquist，带内须至少有两个正频率 bin；不足时应增加窗口或调整频带。
- 零模长、非有限矢量使对应体元在整个窗口无效。部分覆盖也使声音静音；有效子集统计和覆盖率仍可查询，全部不可用的统计导出为 JSON `null`。
- 跳转或修改配置时清空结果缓存并重建目标历史；历史已经存在可立即计算，缺历史则继续预热。NPZ v1 推断帧号，不能据此发现原始缺帧，导出有警告。

诊断区分采样 Δt、历史跨度 `(N−1)Δt`、分辨率和控制线程延迟。窗内加权统计代表过去一段时间，不能称零延迟瞬时测量；未测量从实际物理事件到耳机输出的端到端延迟。音频线程不读帧、不做 FFT。

## 验证记录

数值与交互：`python -m pytest -q` → **128 passed**（2.04 秒）。覆盖单频均方幅值、带外抑制、空间反相、坐标/参考轴共同旋转、极端矢量尺度、缺帧恢复、非均匀时间、Nyquist、窗口切换、无效覆盖、NPZ 往返、倍速与暂停。另实际生成 320 帧 `band_mixed` NPZ 并通过命令行分析、JSON 导出；`git diff --check` 通过。

实际设备：运行 `python launch.py --field-demo band_mixed --audio-smoke 6 --report local/p2c-audio.json`，6.104 秒、106 次更新，OpenAL Soft 1.25.2、Realtek 默认输出，HRTF 状态 enabled，错误为空、意外停止和丢弃更新均为 0；控制生效 p95 为 0.300 ms。全场均方约 0.00235268，带内区域峰值约 0.00499945，与 8/17 分区符合。该次数包含分析和等待时间，不是纯观察器基准。

窗口：实际 Tk 窗口截图检查通过，频带设置、窗宽/分辨率、ROI、表格和音频按钮均可见。本地截图与设备 JSON 留在忽略目录 `local/`。

尚未验证：真实 MuMax 输出、用户耳机上的带内外可辨性、音色舒适度、移动背景抑制、大网格性能、长时运行及声学延迟。设备链路通过不等于人工试听通过。
