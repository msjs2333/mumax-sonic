# P2e：可调声源预算与贡献覆盖

日期：2026-09-09。已将声源预算接入窗口、CLI、映射报告与音频容量诊断，范围 1–16 路、默认 4 路。保留当前固定 4×4 分块，没有增加自适应分块或自动背景汇总；本阶段使已有压缩过程可查询、可比较。

## 使用

```powershell
python launch.py --field-demo activity_rotation --source-budget 16
python launch.py --field-demo opposite_pair --source-budget 8
python launch.py --replay local/ovf-demo.json --recipe band --source-budget 8
python launch.py --inspect-field local/ovf-demo.json --recipe band --source-budget 8 --report local/coverage.json
```

窗口“声源上限 / 分摊音量”可选 1–16，切换后直接更新选源，不重算物理观察量。单路增益沿用 `master_gain / budget × sqrt(min(strength/reference,1)) × ROI_weight`：预算增大时为更多声部预留混音余量，单路声音会变轻。参考尺度、物理强度与统计不随预算改变，不做逐帧自动增益补偿。

16 是当前 OpenAL 池容量上限，不是最多 16 个体元。全网格先计算观察量，再聚合为区域贡献，最后选择声音；一般模式最多 16 个固定块，拓扑每块可有正负两个贡献，仍可能超过 16 路。100% 贡献覆盖也不表示保留了每个体元的空间细节。

## 选择规则与统计

保持 ROI 优先：预算至少 2 时尽量保留圈内正负声部；背景非零且预算至少 3 时，通常为圈外预留一路。预算为 1 时按加权强度选择圈内最强源，无圈内源才选圈外，不再因为循环次序固定偏向正号。零强度或 ROI 权重恰好为零的源不占声部。

选源权重使用平滑 ROI；统计始终使用未加权、未限幅的原始贡献。圈外不等于静音，只有权重为零才计入“关注静音”。同单位但不同物理量/实体也分组，不能把角速率、拓扑荷或频带强度相加。

每组按 `(entity_id, quantity, unit)` 区分，具有 absolute/positive/negative 三个通道。负通道存绝对量，拓扑覆盖分母采用 Qabs、Q+、Q−，从不使用可能为零的 Qnet。

| 字段 | 定义 |
| --- | --- |
| total | 已生成区域候选的原始贡献总和 |
| excluded_sign | 被正负 solo 筛除的贡献 |
| excluded_attention | 通过符号筛选但关注权重为零的贡献 |
| eligible | 通过上述筛选、可参与预算选择的贡献 |
| selected | 在当前预算内选入的原始贡献 |
| omitted_budget | 合格但未分配声部的贡献 |
| output | 已选入且映射增益大于零的贡献；不是设备测量 |
| selected_fraction_total | selected / total |
| selected_fraction_eligible | selected / eligible |

分解顺序为符号筛选 → 关注静音 → 预算选择，各类互斥：`total = excluded_sign + excluded_attention + omitted_budget + selected`，`eligible = selected + omitted_budget`。浮点加和允许舍入误差。零分母为 null（窗口显示 —），数据无效、部分覆盖或预热时统计为 null，不伪装成 0% 或 100%。有效零输入仍是 valid。

暂停且关闭静态探听、总增益为零时，selected 保留选择意图，output 为零。窗口显示选入路数和非零输出候选路数；粗圈仍代表中心在 ROI 内，白点仍代表非零输出候选。设备尚未开启或设备静音不抹掉无声预览，不能用白点证明耳机正在发声。底部音频状态另列目标与占用路数。

## 空间聚合与选源覆盖分开

观察器诊断新增 `spatial_aggregation`，记录正负/绝对通道在固定分块前的 input、分块后 represented、聚合省略 omitted。拓扑、活动和频带按现有定义保持加和；连续取向中，圆周平均退化的块可能无法表示为单一方向，损失会单独显示。

连续取向的 input 是**有效横向投影的权重**，不是全部纹理内容或原始磁化；当前投影有效性规则不变。比如每块都有等量相反角度，物理投影权重非零，圆周平均无法输出角度，程序显示聚合退化省略，不能称零纹理或全覆盖。

`selected_fraction_observer_input` 用选入贡献除以该模式的聚合前观察量，窗口的“观察量覆盖”使用这个分母。候选分母与原始观察量分母同时保留，避免把已经聚合丢失的内容藏起来。比例在浮点舍入处限制到 [0,1]，原始量不改动。

仍未统计对象检出率、听觉掩蔽、弱局部事件检出率、圆周均值的全部形状误差或高频瞬态漏检。提高声源预算能保留更多已聚合贡献，不能恢复聚合中已经丢失的空间细节。

## 诊断与兼容性

`map_sample` 仍返回 SonicScene；新增 `map_sample_with_report` 返回 scene 和 report，所有选择来自同一次计算。预算必须为整数 1–16，拒绝 bool、浮点数、0 或超限。报告保存模式、参考值、主增益、预算和 ROI 参数，便于复核。

GUI 导出包含 selection 和空间聚合统计；`--inspect-field` 每帧也带 selection，使用默认 ROI、both 模式，只作无声预览。`output_enabled` 只表示映射层允许非零增益，数据质量及设备状态分别保存。原有 NPZ/OVF 输入格式不变。

音频报告新增 `source_capacity`、`active_source_count`、`target_source_count`。active 表示已分配源，包括退出选择后正在淡出的声部；target 表示最新场景目标数。预算降低时短暂占用数可高于目标数，但整个池不超过 16。关闭设备后计数归零；设备烟雾检查另记录播放期间峰值，避免只查看停止后的 0 路。

## 验证

**自动测试**：整套测试覆盖预算边界、单路符号偏差、净零拓扑正负守恒、单位隔离、ROI/solo/mute、预热状态保持、取向聚合退化、命令行与 Tk 预算切换。最终 `python -m pytest -q` 为 **167 passed**（7.87 秒），`git diff --check` 通过。模拟 OpenAL 实测分配峰值 16，覆盖 16 → 4 → stale → 16 → stop/close，验证计数、静音和池容量。

**解析基线**：8×8 均匀角活动场，16 个等权分块、背景权重 1；预算 1/2/4/8/16 对应覆盖 6.25%/12.5%/25%/50%/100%，物理活动总量不变。8×8 反相取向棋盘验证聚合输入为 1、候选为 0、聚合省略为 1，覆盖为 0 而非 100%。

**真实小型回放基线**：复用 P2d 已验证的两帧 MuMax+ 回放，在默认 ROI 下比较相同活动量：

| 预算 | 选入路数 | 聚合前观察量覆盖 |
| --- | --- | --- |
| 1 | 1 | 12.15% |
| 2 | 2 | 17.78% |
| 4 | 4 | 33.28% |
| 8 | 8 | 65.59% |
| 16 | 16 | 100.00% |

各档原始活动均值均约 `9.26508e6 rad/s`，未修改源数据。该表展示当前固定分块的贡献分配，不是研究结论或人耳识别率；私人路径和详细 JSON 仅保存在 local。

**实际音频**：16 路解析活动场先运行约 6.109 秒（201 更新），随后为验证峰值计数运行约 4.130 秒（130 更新）。后者设备目标/占用峰值均为 16，OpenAL Soft 1.25.2，HRTF enabled，错误为空，控制提交 p95 约 0.583 ms。未测量声学延迟或人耳多源分辨率。

**窗口**：实际 Tk 窗口检查预算选择、双符号覆盖、表格和底部音频控件；压缩间距后完整可见。没有进行新的真实仿真、头追或人工盲听验收。
