## 1. 运行

先接好准备使用的耳机或音箱，在 Windows 中选为默认输出并设为舒适音量。打开 PowerShell，运行：

```powershell
Set-Location D:\Project\mumax-sonic
python scripts/replay_listening_check.py local/p4-listening/playlist.json --play --seconds 5 --report "local/p4-listening/manual-$(Get-Date -Format yyyyMMdd-HHmmss).json"
```

播放约 42 秒，终端显示当前片段名。可按 Ctrl+C 停止；每段时长可以将 `5` 改为 1–10 秒。重复执行会写新报告，不覆盖上次记录。若只想检查数据而不播放，去掉 `--play`。

播放清单由准备脚本生成，数据来源及重建方法见 `examples/p4_listening/README.md`。本表的本机副本已经填好现有清单路径，可直接使用。暂不修改音色或逐段调整音量，以便比较；如果整体过响或过轻，可以调整系统音量并在下面记录。

这是固定帧探听，每段保持一个声音场，不是动态事件播放。带内两组共用同一参考尺度；FM 与 AFM 的参考不同，不能凭音量直接比较两种体系的活动量。
