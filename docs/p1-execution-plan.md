# P1 细化：无 GPU 的空间听觉原型

日期：2026-09-08。状态：P1 合成原型已实现，短时设备检查通过，听觉验收及 30 分钟浸泡测试待完成。证据见 [P1 验证记录](p1-validation.md)。整体阶段见 [实施计划](implementation-plan.md)，协作规则见 [AGENTS.md](../AGENTS.md)。实现由主代理集成，Terra 负责音频，Luna 负责夹具和行为测试、试听工具。

## 1. 下一步的具体成果

一个在 Windows 上启动的小窗口：显示 3–4 个声源及正负图例，可以播放/暂停、拖动关注区域、调整范围/背景音量、切换正/负 solo 和 both。耳机听到对应空间位置的声音，暂停时可以继续主动探听静态状态。

先由带明确标签的合成声源驱动。界面注明 synthetic/demo：正负只是声音编码测试输入，未计算 q/Q，不宣称拓扑检测已完成。P2 才以从磁化场计算得到的观测结果替换假数据。P1 不接 GPU、不改变真实仿真、不接头追。

最先实现一个声源的启动→移动→增益变化→停止，然后扩展多源和 ROI。第一条链可用后就交付试听，不等全部泛化配方完成。

## 3. 契约冻结内容

v0 最小约定：

- 数据来源区分 synthetic / replay / live。Sample 有实体、量名/单位、规范分量轴与坐标、sim_time 和阶段、有效状态。
- Scene 声源包含稳定 ID、观察引用、物理位置、非负强度和符号标签；符号与位置独立。
- 原始强度、注意权重、映射 gain 各自有定义。ROI 不改变物理数据，也不改变正负积分标签。
- 音频边界初拟 open(config)、update(scene)、stop/close、diagnostics；这些是内部候选接口，不是已存在的库 API。冻结后再并行实现。
- 场景控制有界缓存，旧展示可覆盖；音频线程不读取大数组、文件或执行观察器。设备不可用与静默样本分开。
- 暂停停止时间推进，主动探听静态状态另有开关；关闭主动探听则渐弱到静音。数据过期按独立状态处理。
- P1 的连续角标签仅用于映射试验；不得声称已能从任意畴壁恢复局部内角。

只冻结第一条可运行链必需字段，避免把完整研究 API 实现成 P1 的前置工程。字段缺失的语义不能由模块自行补零。

## 4. 音频技术选择的决策点

OpenAL Soft 是既有首选，P1-02 首先验证本机 DLL、Python 绑定/ctypes、可用 HRTF、设备切换和连续源控制。记录实际加载库及后端，不以成功导入等同于空间音频可用。

普通立体声可以用于对照和设备失败时的明确降级，但不能以其冒充 HRTF 验收完成。若绑定覆盖不足，先比较最小 ctypes 调用；只有两者具体受阻时才评估 Windows 原生实现。UI 框架在 00/01 时按最小依赖和可测试性确定，本计划不凭记忆锁死版本。

## 5. 分层验收

### A. 无声自动检查

- 标签输入正负同时存在，映射后两声部均被保留；net=0 不消除两者。此处验证标签/映射，不验证 q 公式。
- 同一原始强度的正负通道共用数值参考尺度；物理数值不因 solo 或 ROI 改变。
- ROI 外强源不能挤掉已预留的 ROI 内弱源；边界移动平滑、声源 ID 稳定。
- 过期、缺数据、暂停与有效零量有不同状态；不能以有效静默掩盖故障。
- 固定种子/配置下场景可重复；改变数据读取速率不改物理时间标签。
- gain 有界且非负，停止可释放资源。mock 后端验证控制行为，不验证实际设备。

### B. Windows 设备检查

实际设备的库/后端/HRTF 状态、启动停止、掉线重连、播放连续性。30 分钟运行单列为设备浸泡测试，不放进每次单元测试，也不能由 mock 代替。日志只能覆盖可检测错误，不能证明人耳完全没有断续。

控制更新应用端 p95 延迟先以 100 ms 为预算，必须定义测量边界；没有回环或声学测量时，不报告“耳机端到端延迟”。蓝牙链路延迟单独处理。

### C. 人工试听

耳机/音量/HRTF/映射配置记入本地记录。粗左右和同位置正负二选一，各至少 20 个随机试次，以至少 90% 为初始工程目标；多源/上下和连续取向先记录混淆，不预设达标。

主代理可完成代码与设备检查，但不能替用户作主观辨识。若当时无法人工试听，交付可运行小样和待测记录，阶段明确为“工程完成，听觉验收待完成”，不把待测记为通过。

## 6. 向 P2 的衔接

P1 确认音频与 ROI 可用后，首先加入二维拓扑观察器和连续取向小配方，让假标签被真实场计算替换；随后加入频带与更完整壁追踪。四种核心模式仍是首个可用版本范围，P1 只缩短最早可试听链路。

建议 P2 并行：Terra 实现已冻结的二维 q/Q 计算与场聚合，Luna 建独立解析/变换夹具，主代理审查符号、边界、网格收敛并接入已有场景。通过净零双瓣、坐标变换和整体自旋旋转后，再扩展真实回放。
