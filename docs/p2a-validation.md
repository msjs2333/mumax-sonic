# P2a：三分量场、拓扑与连续取向

日期：2026-09-09。本批为 P2 的第一部分，已实现并验证解析场到观察值、空间贡献和音频控制的链路，不代表完整 P2 完成。用户试用 P1 后表示角度与半径问题不构成阻碍，授权进入下一部分；音色美化保留为后续迭代，不将这次反馈记录成定量盲听成绩。

## 实现范围

- `FieldFrame`：规则 XY 截面的 XYZ 三分量、米制间距、首个采样中心坐标、布尔材料 mask、实体、时间、来源与阶段。保留原模长与无效向量，观察器内部归一化。
- `topology`：中心差分与有向三角形立体角两种方法，开放边界或双轴周期边界；正负贡献先分开再聚合。正旋转不改 Q，整体自旋反演、积分面反向会改符号。
- `direction_angle` / `wall_angle`：相对显式域轴和参考轴构造右手基底，保留连续角与圆周表示；零投影、零向量、退化基底无效。`wall_angle` 要求有顺序的近反平行两侧域方向。它们不自动寻找壁、追踪对象或处理分叉。
- 场景：均匀场、紧支撑单纹理、正负双纹理、面内/面外域轴的解析壁。都是 CPU 解析夹具，不是 MuMax 求解结果。
- NPZ 回放与无声批量检查、窗口选择与加载场、XYZ 简图、真实拓扑汇总、周期连续的取向声音控制。

## 计算与声音的约定

数组顺序 `(ny,nx,3)`，分量 `(x,y,z)`；物理轴右手，默认积分面法向 +z。立体角每个四边形按 `(00,10,11)`、`(00,11,01)` 三角化；每个三角形先分正负，再累加到格子。结果数组存无量纲贡献，不是直接的 q 密度。声音位置取格子中心；周期接缝中心使用未折回坐标。

开放立体角域是样点间四边形，不包含外侧半格；开放中心差分只使用内部完整五点模板，贡献为 q·dx·dy。两种方法的离散与支撑域不同，Qabs 不能逐点混比。输入欠分辨、近反平行三角形或 atan2 分支歧义会报告警告或排除无效支撑。原始总量不取整。

覆盖率的分母为本方法原本可构成的模板数，mask 洞和无效材料会降低覆盖率，不跨真空连接。积分只在有效支撑上求和，全无效时为 NaN；GUI 保守地将覆盖不完整的样本置 invalid 并静音，同时保留部分域数值供诊断。当前不把这种部分积分解释成完整样品的 Q。

原网格先计算，再划分固定 4×4 空间块。每块保留正负两路和各自贡献加权位置，所有块之和守恒；之后才做 ROI、solo 与最多 4 路声音裁减。圆表示贡献块，不是检测出的粒子。播放层沿用固定参考值 1 和平方根压缩，超过参考值会饱和，但显示原始数值不变。

取向配方用横向投影模平方作非负面积权重，块内用圆周均值合角；相反方向抵消、无法形成单值角的块不输出角声源。这里的面积权重不是拓扑荷。初步声音编码为 `pitch=2^(0.25 cosφ)` 与 `tremolo_hz=4+2 sinφ`，起伏深度 0.25；控制参数平滑且跨 ±π 连续。两参数保留角的两个圆周分量，但尚未证明人耳可准确反推角度。Hz 是听觉调制参数，不是自旋波频率。

## NPZ 交换格式 v1

通过 `sources.replay.save_replay(path, frames)` 生成；写入不覆盖已有文件。文件包含：

| 字段 | 含义 |
| --- | --- |
| vectors | 浮点 `(nt,ny,nx,3)`，完整三分量 |
| mask | 布尔 `(nt,ny,nx)` |
| times_s | 长度 nt，有限、非负、严格递增的仿真秒 |
| metadata | Unicode 标量 JSON：schema_version=1、axes=yx、components=xyz、spacing_unit=m、dx_m/dy_m、origin_m、entity_id、segment_id、time_kind、original_source_kind |

单个文件内网格、实体、阶段与时间类型固定。加载禁用 pickle，文件及解压内容各限 256 MiB，并记录实际文件 SHA256；当前整段加载到内存。回放按真实时间选择前一测量帧，不插值矢量，到末帧自动暂停，静态探听仍由开关决定。时间类型/原来源保留，但没有活动和频谱处理，因此尚不实现它们的缺帧滤波预热。

`--inspect-field` 支持两种拓扑方法；GUI 的 NPZ 回放当前固定使用开放边界、立体角、+z 截面。周期边界和其他取向基底可通过 Python API 显式选择。尚无 OVF 读取器、MuMax 实时适配、自动坐标推断或真实私有数据验证。

## 已运行检查

Windows，Python 3.13.12，NumPy 2.5.2，Tk 8.6，OpenAL Soft 1.25.2。

| 检查 | 实际结果 |
| --- | --- |
| 全量 `python -m pytest -q -rs` | 67 passed，无跳过；包括拓扑、连续取向、回放、聚合、GUI 和旧音频回归 |
| 解析净零双纹理保存→加载→计算 | 65×65：Q+=1、Q−=1、Qnet=0、Qabs=2，coverage=1 |
| 独立拓扑测试 | 均匀场、BP 收敛、正旋转、反演、换轴、正负抵消、mask、周期与分支退化，共 14 项 |
| 两种方法的有限 BP 例 | 65×65：立体角 −0.987384，中心差分 −0.946707；不强制整数或方法一致 |
| 观察器局部计时 | 子代理 100 次均值：65×65 立体角 1.721 ms、差分 1.202 ms；不是整应用实时性能承诺 |
| 连续角设备短测 | 8.128 秒，HRTF enabled，无报告错误/异常停声/丢更新，关闭后 closed |
| 控制提交延迟 | 短测最后 128 次滚动 p95=0.432 ms；不是声学或耳机端到端延迟 |
| 窗口 | 实际解析场窗口视觉检查；ROI/solo 不改 Q，面外取向输出启用连续声音控制 |

测试期间再次遇到本机多次创建 Tcl 解释器的偶发 init.tcl 读取失败；测试夹具改为共用一个解释器、各测试独立窗口后，上述全量通过。临时图像和设备日志仅保存在被忽略的 `local/`，不提交桌面信息或机器路径。最后短测曾因自动审批服务报告额度耗尽未执行，用户要求继续后原检查成功重试。
