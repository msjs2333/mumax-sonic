# P3d：有界活动分块与控制周期

2026-09-12。本批继续减少大关注区观察成本和 UI 控制更新的额外等待。

## 实现与数值语义

活动核由逐行 NumPy 操作改为最多 4096 体元的二维矩形块，显式计算 XYZ 的有限性、缩放、点积和叉积。保持 `atan2(|a×b|, a·b)/dt`、完整体元分辨率、材料掩膜和既有有效性/采样混叠提示。不扁平化输入，避免 Fortran 布局触发整帧复制；临时数组受块大小限制。仍输出逐体元角速率及有效性数组。

UI 原先每次 tick 完成后等待 33 ms，实际周期还要加上绘制等处理时间。本批按 tick 开始时间补偿处理耗时，目标仍是约 30 Hz；超时后至少让出 5 ms，不排队补帧。没有降低文件轮询间隔，没有改变音频平滑或物理采样时间。

## 独立测量

真实 500×1500 帧对九次中位：旧逐行核约 108.0 ms；4096 体元块约 41.2 ms；8192 块约 38.5 ms；16384 块约 40.7 ms。选择最小的有明显收益方案，避免为了这组样本的小幅差异扩大临时工作集。

## 180 秒持续结果

同一原备份路径、1500×500 场、约 1.426 秒/帧、四阶段各 45 秒，目标预算 8 路，stale 2 秒。生产读取算法不变。

| 场景 | 发布→控制中位 / p95 | 新帧观察中位 / p95 |
| --- | ---: | ---: |
| 小圈静止 | 187 / 534 ms | 5 / 10 ms |
| 大圈静止 | 214 / 241 ms | 40 / 64 ms |
| 小圈拖动 | 187 / 221 ms | 7 / 14 ms |
| 大圈拖动 | 234 / 269 ms | 37 / 48 ms |

大圈观察从上一轮约 90 ms 的量级下降，但读取阶段 p95 再次升到约 150–174 ms。小圈静止的观察完成→控制 p95 约 404 ms、发布→控制最大约 1.20 秒；同阶段 tick 函数自身最大约 18 ms，现有证据不能把额外等待归因于函数内的绘制。本批未证明调度补偿在当前运行环境下消除了控制长尾。

127 帧全部观察到，125 帧记录到有效控制应用；首帧 0 预热，帧 26 未记录到首次原生控制应用，不能声称每帧都播放。未抽样到 stale；发布/读取错误、音频异常停止和音频线程丢弃更新计数为零。帧级未应用与音频丢弃计数含义不同。

CPU 核当量约 0.92（上一轮约 1.11），RSS 抽样最大约 200 MB（上一轮约 221 MB）。目标预算为 8，切换过渡时原生声源抽样最大 11，最终 8。不同轮的系统负载未受控，不能把所有差异归于这两项修改，也不作为长期或峰值保证。

**100 ms p95 目标仍未全面通过，端到端长尾仍需定位。** 本轮确认的是计算核和局部观察成本下降。

完整回归 **288 passed**；新增解析测试覆盖 C/F 内存布局及两个方向跨块边界，UI 测试覆盖正常周期补偿和超时不积压补帧。实际设备测试为归档场驱动 Windows Tk/OpenAL，HRTF 报告 enabled；未重跑 GPU 仿真或人工试听。控制延迟不包含求解器、OVF 写出、桥接稳定等待、设备缓冲和听觉平滑完成。
