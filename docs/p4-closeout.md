# P4 工程收尾与对照试听

2026-09-22。P4a 公开 FM、P4b 双子晶格 AFM、P4c 真实进动频带已完成各自的数据与观察器验证。本次补充可复现的固定帧对照试听入口和原生音频设备检查；不将其等同于人耳验收或完整泛化能力认证。

## 收尾交付

- [准备脚本](../scripts/prepare_p4_listening.py)将已有三阶段结果组合为 8 段标注来源的播放清单，不重新运行 GPU 仿真。
- [试听脚本](../scripts/replay_listening_check.py)默认只验证；显式 `--play` 才打开设备。先读完数据并计算物理观察和声音场，再在音频线程外定时提交固定场景，音频线程不读文件、不求解物理。
- [试听说明](../examples/p4_listening/README.md)列出执行命令、顺序、固定参考尺度和需要人耳判断的内容。无效窗口拒绝探听，报告不覆盖，Ctrl+C 后释放设备。

播放包含真实 FM/AFM 活动和三组真实频带窗口，以及正、负、净零双纹理三个合成拓扑场。所有声音共用 0.2 总增益缩放、8 路预算；三组频带共用 0.01 强度参考，拓扑共用 1。FM 与 AFM 的活动参考不同，不进行跨案例绝对音量大小判定。

## 阶段边界与后续

P4 当前计划中的工程实现和小型对照案例可在此收尾，人耳可辨性等待实际反馈。更完整的壁识别、传播自旋波、三子晶格、部分缺子晶格接口、耦合配方、多实体切换和大网格频带内存仍是显式后续项目，不在本批承诺为通过。

后续主线可进入 **P5a 姿态模拟输入**：先实现回中、锁定、掉线及手动注意力与头部偏移的组合语义，再接真实头部追踪设备。听觉反馈若显示音色或强弱不易辨，应先作局部调整；P3e 仍按实际性能瓶颈单独启动。
